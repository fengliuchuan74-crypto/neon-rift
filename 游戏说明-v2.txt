霓虹跃迁 NEON RIFT 2.0
赛博朋克像素横版冒险 · 武器与机关更新

启动与退出
双击「霓虹跃迁.exe」，按 Enter 或点击「开始游戏」。
主菜单、关卡选择、通关画面及暂停菜单均有「退出游戏」。
游玩中按 Esc 打开暂停菜单，再点击「退出游戏」。
退出确认框：Enter 确认退出，Esc 取消。关闭窗口或 Alt+F4 也可以退出。

本次更新
1. 新增明确的退出按钮和退出确认界面。
2. 中文和所有界面文字按窗口实际分辨率显示，场景继续保持像素风。

基础操作
A / D 或 ← / →：移动
空格 / Z / ↑：跳跃；在空中再按一次可以二段跳
长按跳跃跳得更高，轻按可以短跳
1 / 小键盘 1：相位冲刺，可空中使用，冲刺期间无敌，撞击敌人造成伤害
2 / 小键盘 2：电磁脉冲，震晕敌人，清除附近子弹，暂时关闭附近机械伤害机关
J / X：使用当前装备武器；可以按住连续攻击
Q / E：向前 / 向后切换已拥有的武器
B / Tab：打开 / 关闭武器背包
F：靠近终端时开启对应闸门
R：回到最近检查点；暂停菜单中的 R 则重新开始整关
Esc：暂停 / 继续；背包打开时关闭背包
F11：全屏 / 窗口
M：开启 / 关闭音乐与音效

武器背包
背包打开时世界暂停，便于查看武器和装备。
使用方向键选择卡片，按 Enter 装备；也可以用鼠标选择并点击装备。
初始拥有脉冲刃和离子手枪。磁轨霰弹枪和电弧长枪藏在屋顶支路武器箱中。
触碰新武器后自动拾取、装备并永久解锁。后续进入其他关卡或重启游戏也可使用。
重复拾取已拥有的武器箱会恢复少量生命。
武器不消耗弹药，通过攻击间隔区分手感；换武器不会清空当前攻击冷却。

四种武器
脉冲刃：快速近战，伤害 1，攻击间隔 0.29 秒，可挥中身前多个敌人。
离子手枪：远程连射，单发伤害 1，攻击间隔 0.24 秒。
磁轨霰弹枪：一次发射 3 枚弹丸，每枚伤害 1，攻击间隔 0.65 秒。
电弧长枪：较长距离的重型近战，伤害 3，攻击间隔 0.72 秒。
武器攻击会被实体墙壁和未打开的闸门阻挡。

机关指南
移动平台：带着角色移动，可以等待合适时机再跳。
传送带：表面有方向箭头，站立时会向箭头方向推动角色。
弹射板：橙色弹簧结构，落上后自动向上弹射，可继续进行空中跳跃。
坍塌平台：橙色裂纹平台，踩上短暂延迟后塌落，数秒后重建。
移动锯刃：沿轨道往返，观察路线后跳过或使用脉冲关闭伤害。
喷火口：周期喷火，熄火间隙通过，或使用电磁脉冲。
液压压机：上下运动的落锤，等待抬升后快速通过。
终端闸门：靠近控制台按 F，永久打开本次关卡内对应的门。
激光：周期通断，也可以用脉冲临时关闭。
尖刺：需要跳过或冲刺避开，脉冲无法关闭。

三个区域
01 霓虹街区：屋顶武器、深层街道、传送带与终端教学。
02 悬空货运线：升降货台、运输带、空中支路和组合机关。
03 核心反应炉：双终端防线、更多火力和最终机关长廊。
每关必须回收 3 枚金色核心，再进入末尾传送门。
蓝色晶片是可选收集物，绿色医疗包恢复生命。
触碰检查点信标会恢复生命并更新重生位置。

存档兼容
旧版已经解锁的关卡会保留。
关卡解锁、已获得武器和装备选择自动保存到：
%LOCALAPPDATA%\NeonRift\progress.txt
关卡内的检查点、核心、晶片和已打开的门只在本次关卡游玩中保留。
返回关卡选择或关闭游戏后，再次进入关卡会从起点开始。

运行和源码
Windows 10 / 11，使用系统 .NET Framework 4.x。
单个 EXE 包含美术、音乐、图标与游戏逻辑，无需联网或安装素材。
完整包的「源代码」目录含 C# 源码、头像图标和 build.ps1。
运行 build.ps1 可重新生成 NeonRift.exe。
